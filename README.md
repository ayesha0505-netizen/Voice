# voice – Find Your Words. Express Yourself.

![voice Logo](/public/logo.png)

> **Find Your Words. Express Yourself.**

Turn speaking practice into an exciting game! Spin the wheel, discover random words, beat the timer, and express your thoughts through sentences and stories. Challenge yourself, improve your vocabulary, overcome hesitation, and build confidence with every round.

*Find your words. Speak your mind. Let your voice shine!*

---

## 🎮 About voice

**voice** transforms speech articulation and pronunciation training into a fun, interactive game. Climb through stages, calibrate your microphone, spin words, match target cadence, and earn stars and badges as you build fluency.

- **Brand:** **voice**
- **Tagline:** **Find Your Words. Express Yourself.**
- **Logo:** `public/logo.png`
- **Core Loop:** Spin words, beat the cadence timer, level up, and unlock scholar badges.

---

## 🚀 Getting Started

First, install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to experience **Voice**.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router & Turbopack)
- **UI & Styling:** Tailwind CSS 4, Material Symbols & Lucide Icons
- **Speech APIs:** Web Speech API (Speech Recognition & Synthesis)
- **Visuals:** Canvas Confetti, Framer Motion
